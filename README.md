# Industrial Vision

Программный модуль технического зрения для
промышленного мобильного роботизированного комплекса.

## Назначение

Проект предназначен для анализа видеопотока
с использованием технологий компьютерного зрения.

Планируемые функции:

- Обнаружение людей и транспорта.
- Отслеживание объектов.
- Контроль запрещённых зон.
- Проверка наличия каски и жилета.
- Обнаружение дыма и огня.
- Исследование обнаружения разливов жидкости.
- Формирование и сохранение событий.
- REST API для получения результатов.

## Технологии

- Python
- OpenCV
- PyTorch
- YOLO
- FastAPI

## Установка

Создать виртуальное окружение:

python -m venv .venv

Установить зависимости:

python -m pip install -r requirements.txt


## Запуск

1. Создать виртуальное окружение Python.
2. Установить библиотеки из requirements.txt.
3. Поместить тестовое видео в data/test_video.mp4.
4. Указать источник в configs/configuration.yaml.
5. Запустить программу:

```powershell
python main.py
```

Для остановки нажать Q в окне видеопотока.

## Реализованные функции

- Получение кадров из видеофайла.
- Поддержка камеры через OpenCV.
- Отображение видео.
- Измерение FPS обработки.
- Проверка доступности источника.
- Базовая обработка ошибок и повторное подключение для потоковых источников.
