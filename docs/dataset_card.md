
# Dataset Card: Construction-PPE

## 1. Назначение
Набор данных используется для дообучения
нейросетевой модели YOLO с целью обнаружения
средств индивидуальной защиты работников.

## 2. Источник
Ultralytics Construction-PPE Dataset

https://docs.ultralytics.com/datasets/detect/construction-ppe/

## 3. Размер
Всего изображений: 1416

Train: 1132
Validation: 143
Test: 141

## 4. Классы
0 - helmet
1 - gloves
2 - vest
3 - boots
4 - goggles
5 - none
6 - Person
7 - no_helmet
8 - no_goggle
9 - no_gloves
10 - no_boots

## 5. Формат разметки
YOLO Object Detection.

Каждый объект описывается классом
и координатами ограничивающего прямоугольника.

## 6. Разделение данных
Используется готовое разделение набора данных
на Train, Validation и Test.

Дополнительная проверка пересечения сцен
и похожих изображений будет выполнена
при анализе данных.

## 7. Hard negatives
Предстоит проверить изображения людей
с обычными головными уборами, без касок
и в одежде, похожей на защитные жилеты.

## 8. Ограничения
Качество распознавания может снижаться
при плохом освещении, перекрытии объектов
и небольшом размере людей на изображении.

Эти ограничения будут проверены экспериментально.
