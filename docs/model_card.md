
# Model Card — YOLO26n PPE Detection

## 1. Назначение модели

Модель предназначена для обнаружения
средств индивидуальной защиты работников
на изображениях и видеопотоках.

## 2. Архитектура

Модель: YOLO26n
Библиотека: Ultralytics
Тип задачи: Object Detection
Исходные веса: yolo26n.pt

## 3. Набор данных

Название: Construction-PPE
Общее количество изображений: 1416

Train: 1132
Validation: 143
Test: 141

Количество классов: 11

## 9. Ограничения

Модель демонстрирует высокое качество обнаружения
видимых касок и жилетов на тестовом наборе.

При этом качество обнаружения класса no_helmet
остаётся низким.

Необходимо дополнительно исследовать работу модели
при плохом освещении, перекрытии объектов
и небольших размерах работников в кадре.

Результаты не являются подтверждением пригодности
системы для промышленной безопасности.
